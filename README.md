# 網頁繪本 Demo（GitHub Pages 版）

這是一個可直接上傳到 GitHub Pages 的第一版範例。

## 功能
- 左右雙頁書本顯示
- 點擊左右半邊翻頁
- 上一頁 / 下一頁按鈕
- 翻頁音效
- 每次翻頁後，依序播放左右頁的 MP3
- 手機版自動改成單頁閱讀

## 檔案結構
- `index.html`：主畫面
- `style.css`：樣式與翻頁動畫
- `app.js`：翻頁與音訊控制
- `book-data.js`：頁面資料設定
- `images/`：JPG 圖片
- `audio/`：MP3 音檔

## 如何替換成您自己的內容
### 1. 更換圖片
把 `images/` 裡面的檔案換成自己的 JPG，或在 `book-data.js` 中修改檔名。

### 2. 更換聲音
把 `audio/` 裡面的 `p001.mp3`、`p002.mp3` ... 換成您的頁面朗讀音檔。

### 3. 修改頁面數量
直接編輯 `book-data.js`，依照格式新增或刪除：

```js
{ image: "images/p007.jpg", audio: "audio/p007.mp3", label: "第 5 頁" }
```

## 重要說明
因為瀏覽器通常禁止未經使用者互動就自動播放有聲音內容，所以本版本設計成：
1. 使用者先按一次「開始閱讀」
2. 之後翻頁時，才自動播放該頁 MP3

## GitHub Pages 發布方式
1. 把整個資料夾上傳到 GitHub repository
2. 到 repository 的 Settings → Pages
3. Source 選擇部署分支，例如 `main`
4. 幾分鐘後即可取得網站網址
